# Veyl

Личный сайт Veyl: Minecraft / Web / Systems. Vue 3, TypeScript, Vite и Pinia; сервер на Fastify и SQLite. Тёмная тема по умолчанию, переключатели RU / EN и светлой темы, CSS-анимации с облегчённым режимом.

## Запуск

Нужны Node.js 24 и pnpm 10.

```sh
pnpm install --frozen-lockfile
pnpm setup
pnpm dev:server
```

Во втором терминале:

```sh
pnpm dev
```

Сайт: http://127.0.0.1:5173/. Панель: http://127.0.0.1:5173/admin.

`pnpm setup` создаёт случайный пароль и его scrypt-хеш. Пароль записывается только в локальный `work/admin-access.txt`; параметры сервера - в `.env.local`. Существующее окружение сохраняется. Секреты, чаты, база данных и загруженные изображения исключены из Git.

## Что работает

- 113 инструментов в 10 категориях; поиск, 14 кейсов и 19 записей портфолио. Дополненные описания кейсов доступны для уточнения в панели.
- Управление проектами: добавление, редактирование, порядок, видимость, состояние, роль, перевод, ссылка и загрузка обложки.
- Редактирование основных текстов и контактов на двух языках.
- 11 начальных статусов, собственные статусы, время окончания и недельное расписание по Москве. Статус «Занят проектами» показывает количество и при желании названия работ. Временный статус имеет приоритет над расписанием.
- Чат посетителя с сохранением сессии и сообщений, ответами владельца и обновлениями через SSE.
- Диалоги в панели: поиск, непрочитанные, архив, закрепление, блокировка, закрытие, личные заметки, быстрые ответы и отметки прочтения.
- Серверная проверка пароля, HttpOnly-сессии, ограничение попыток входа и отправки сообщений, проверка Origin. Смена пароля завершает все сессии владельца.
- Настройки внешнего вида сохраняются в браузере; содержание сайта, статусы и сообщения - в SQLite.

Старые серверы отделены от текущих работ. Закрытые проекты отмечены явно; где нет актуальных сведений, указано завершение участия владельца. Java обозначена как базовый уровень. Контакты владельца: Telegram @veyldev, Discord veyl.core; они доступны для изменения в панели.

## Проверки

```sh
pnpm test
pnpm build
```

Тесты проверяют доступ к админке, изоляцию диалогов, приватность заметок, ограничения ввода, конфликт сохранений, фильтрацию скрытых проектов, лимит входов, смену пароля после перезапуска и расписание статусов. Подключение GitHub Actions ожидает отдельного разрешения workflow; локальные проверки доступны сразу.

## Публичное портфолио на GitHub Pages

Адрес: https://veylcode.github.io/. Репозиторий `veylcode/veylcode.github.io`, ветка `gh-pages`, содержит только собранное портфолио и данные из публичного API. Кнопки связи открывают Telegram. Серверная админка, чат и live-статус доступны в полной версии на Node.js; статическая публикация их не имитирует.

Для обновления запустить локальный сервер и выполнить `pnpm publish:pages`. Скрипт экспортирует текущие публичные тексты, проекты, кейсы и обложки, собирает отдельную версию с правильными путями и обновляет `gh-pages` обычным коммитом. Локальная база, пароли и диалоги не экспортируются. GitHub Pages публикует эту ветку автоматически; изменения `main` требуют повторного запуска публикации.

## Публикация полной версии

Нужен хостинг с Node.js или Docker и постоянным диском. GitHub хранит исходники; GitHub Pages сам по себе не поддерживает серверную админку и чат.

1. Запустить `pnpm setup` на сервере и установить в `.env.local` `PUBLIC_ORIGIN=https://your-domain`.
2. Запустить `docker compose up -d --build` или собрать `pnpm build` и запускать сервер с `NODE_ENV=production`.
3. Настроить HTTPS-прокси по `deploy/Caddyfile.example`. Docker публикует приложение только на локальном порту 3001.
4. Сохранять резервную копию всего тома `veyl-data`, включая базу и uploads. При копировании файлов SQLite остановить приложение либо использовать SQLite backup API.

После первого запуска хеш пароля хранится в базе; менять пароль следует в панели. Потеряв доступ, восстанавливайте его через защищённый доступ к серверу, а не через публичный HTTP endpoint. Никогда не публикуйте `.env.local`, `work/admin-access.txt`, базу или экспорт диалогов.

## Структура

- `src/views`, `src/components` - публичный сайт и панель, отдельные загружаемые маршруты.
- `src/stores`, `src/composables` - состояние, API, язык, жизненный цикл анимаций.
- `server` - авторизация, валидация, SQLite, расписание и SSE.
- `tests` - проверки серверных границ.
- `public/assets`, `public/fonts` - оптимизированные предоставленные изображения и локальный Manrope с лицензией OFL.
- `docs/architecture.md` - границы данных, компоненты и ограничения проверки.

Иллюстрации предоставлены владельцем Veyl. Открытая публикация репозитория не меняет права на фирменные изображения.
